# 브라질 NTN-F 국채 수익률 시뮬레이터

브라우저에서 바로 실행되는 단일 `index.html` 파일입니다. 실시간 시세를 수집하지 않으며 모든 숫자는 사용자가 입력하는 시나리오입니다.

## GitHub Pages 배포 (초보자용)

1. https://github.com 에서 로그인합니다.
2. https://github.com/new 에서 저장소 이름을 `brazil-bond-simulator`로 입력하고 **Public**을 선택해 생성합니다.
3. 저장소의 **Add file → Upload files**를 누르고 이 폴더의 `index.html` 파일을 업로드합니다. ZIP 파일 자체를 올리지 마세요.
4. **Commit changes**를 눌러 저장합니다.
5. 저장소 **Settings → Pages**에서 **Source: Deploy from a branch**, **Branch: main**, **Folder: /(root)**을 선택하고 **Save**합니다.
6. 잠시 후 `https://깃허브아이디.github.io/brazil-bond-simulator/` 주소에서 확인합니다. Settings → Pages에서 실제 배포 주소를 확인할 수 있습니다.
7. 이후 수정할 때는 저장소에서 `index.html`을 열고 연필 아이콘으로 편집 후 **Commit changes**하면 자동으로 재배포됩니다.

## 주요 기능

- 매수 원화 투자금, 기준 BRL/KRW, 매수 YTM, 잔존만기, 보유기간 입력
- 금리 변화(%p)와 BRL 가치 변화(%) 슬라이더
- 중도매도 / 만기보유 자동 전환 (보유기간이 만기와 같으면 만기보유)
- 쿠폰 지급 시 원화 환전 또는 BRL 보유
- 쿠폰 세율, 매도차익 세율, 매수·매도 수수료, 편도 환전 스프레드 입력
- 원화 수익률·회수액·현금흐름 및 금리×환율 매트릭스
- 인쇄/브라우저 PDF 저장

## 모델 가정 및 한계 (중요)

- **실제 거래 견적 산출용이 아닙니다.** 실제 NTN-F는 브라질 시장 영업일(252일) 할인·가격 산식, 결제일, 경과이자, 실제 쿠폰 날짜와 채권별 현금흐름이 필요합니다.
- 모형은 매수일을 쿠폰 지급 직후로, 만기 및 보유기간을 6개월 단위로 설정합니다.
- NTN-F의 **연 유효 10% 고정 쿠폰**을 가정하며 반기 쿠폰은 액면가 × `(sqrt(1.10)-1)`입니다. YTM은 연 유효 수익률로 입력받고 반기 할인율은 `sqrt(1+YTM)-1`입니다.
- 액면가 1,000 BRL, 소수 채권 수량 허용, 쿠폰 재투자 없음.
- 쿠폰 환율 경로는 시작·종료 환율 간 선형 보간으로 가정합니다. BRL 보유 방식은 종료 시 일괄 환전합니다.
- 쿠폰세는 지급액에 적용하며 매도차익세는 BRL 기준 양(+)의 가격차익에만 적용하는 **임의 단순화**입니다. 세율 기본값 0은 면세를 뜻하지 않습니다.
- 매수 수수료는 초기 취득 비용에, 매도 수수료는 최종 매도/상환액에 적용합니다. 환전 스프레드는 매수·매도 편도 각각 적용합니다.
- 만기보유의 원금은 시장 YTM 변화에 영향을 받지 않습니다. 쿠폰·원금에 대한 환율위험은 남습니다.
- 사용자가 입력한 수치 외에 실시간 시장 데이터는 없습니다. 투자 판단 및 고객 제공 전에 실제 ISIN 조건과 세무·판매사 호가를 검증하세요.
